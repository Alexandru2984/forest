YOUR FIELD GUIDE

A new way to see your work.

Each tree represents a public GitHub repository. Its color follows its main language. Glowing leaves represent a sample of recent commits. Trees without samples still grow a small canopy.

Make yourself at home

Drag the forest to orbit, scroll or pinch to zoom, and select a tree to inspect a repository. Use the collection for the same details with a keyboard or screen reader. The focused canvas also supports arrow keys to pan.

Follow your curiosity

Search names, descriptions and topics. Filter by language, stars or dates, sort the collection, and save favorites on this device. Select a language in the chart to filter. Details include focus controls and canonical GitHub links.

A considerate view of GitHub

The API returns up to 500 public repositories, with up to 20 recent commits per sampled repository. The default sampling budget is 20 repositories and can be lower when GitHub quota runs low. Counts are samples, never a complete contribution history. Cached data lasts up to 10 minutes by default.

Tokens are optional and stay in memory. The demo is fictional and makes no GitHub API requests. Share links and exports never include tokens or favorites.
